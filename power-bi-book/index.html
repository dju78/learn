Are the datasets free to download?

Yes. The chapter packs and Brightway workshops are provided as companion learning materials. Every sample organisation and dataset is fictional.

What software do I need?

Use Power BI Desktop on Windows for the exercises. A spreadsheet tool can help inspect CSV files. Some optional publishing exercises require the Power BI service and suitable permissions.

Why do Chapters 1 and 3 not have separate packs?

Chapter 1 introduces KPI logic and manual calculations. Chapter 3 uses the validated Northstar sales data prepared in Chapter 2, so you can reuse that dataset rather than download unnecessary duplicates.

Where are the Brightway workshop files?

You can download the complete Brightway workshop pack below, including the continuing sales, survey and finance/operations exercises and answer workbooks. Key CSV control totals have been independently checked.

How will errors or updates be handled?

Updated files will have a dated release record. Each download has a checksum in the resources manifest so later revisions can be identified.

Download privacy and file integrity

Downloads are provided directly as ZIP files; this learning page does not request logins or collect survey answers. Use the resource manifest to check file versions and SHA-256 checksums. No confidential organisational data is included in the supplied synthetic packs.
